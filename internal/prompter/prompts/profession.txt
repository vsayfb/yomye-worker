Extract structured gig details from the Turkish marketplace text.

Return valid JSON only:
{
  "category": "",
  "title": "",
  "profession": "",
  "duration_type": "",
  "pay_amount": null,
  "pay_currency": "TRY",
  "expires_at": null
}

Rules:
- category and profession are the same primary profession in normalized, singular Turkish.
- title is a short natural Turkish marketplace title, maximum 80 characters.

- pay_amount is numeric or null.
- pay_currency is an ISO-4217 code; use TRY when omitted.
- expires_at is always null.
- Do not invent missing details.
